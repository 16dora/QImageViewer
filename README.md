# QimageViewer

QimageViewer 是一个基于 Qt 6、C++20 和 Qwt 的桌面图片查看器。项目围绕图像查看与像素分析提供缩放、平移、ROI、辅助图形、绝对角度旋转、中心翻转、像素 Pick，以及所选像素所在行列的强度剖面显示。

当前项目使用 `QImage` 保存原始图像、旋转图像和 ROI 数据，以便读取灰度或 RGB 通道的 8 位、16 位原始强度；界面显示时再转换为 `QPixmap`。

## 功能概览

### 图片加载与查看

- 加载本地 PNG、JPG/JPEG 和 BMP 图片。
- 按图片宽高比自动适配主视图。
- 使用鼠标滚轮，以光标位置为锚点等比例缩放。
- 实时显示相对于图片像素的实际缩放倍率。
- 按住鼠标右键拖动平移图片。
- 窗口尺寸改变后重新自适应图片。

### 动态缩略导航

- 当图片任一方向超出主视口时，在右上角自动显示完整图片缩略图。
- 使用黄色细框标示主视口当前对应的图片区域。
- 图片能够完整显示时自动隐藏缩略图。
- 缩略图固定在视口中，不随主图移动，也不包含 ROI 或辅助图形。

### ROI 选择与预览

- 在 `ROI` 模式下使用左键拖动绘制红色矩形选区。
- ROI 始终限制在当前图片的外接矩形画布内，并随图片缩放和平移。
- 右侧区域实时显示 ROI 预览。
- 旋转后产生的无效画布区域使用黑色填充，ROI 可以部分或完全选中这些区域。
- 当 ROI 同时包含真实图像和黑色无效区域时，预览使用蓝色闭合轮廓标示真实图像范围。
- 蓝色轮廓只存在于预览副本中，不会写入底层 ROI 数据。

### 辅助图形

主视图提供五种互斥的左键工具，默认选择 `ROI`：

- `ROI`：绘制用于右侧预览的红色矩形选区。
- `Line`：绘制天蓝色直线。
- `Circle`：以按下位置为圆心、拖动距离为半径绘制天蓝色圆。
- `Rect`：以按下位置和释放位置为对角点绘制天蓝色矩形。
- `Pick`：选择一个有效原图像素并更新行列强度剖面。

Line、Circle 和 Rect 支持实时预览。切换到对应工具后，可以单击同类图形进行单选，再按 `Delete` 删除；绘制过程中按鼠标右键可以取消本次绘制。覆盖图形的显示线宽、Pick 标记大小和选中容差不受主图缩放倍率影响。

### 绝对角度旋转

- 旋转角度范围为 `0°` 到 `180°`，相邻选项步进为 `22.5°`。
- ComboBox 中的角度是相对于原图的绝对目标角度，正值表示顺时针旋转。
- 每次从未旋转原图重新生成结果，避免累计旋转造成重复插值损失。
- 旋转画布自动扩展，画布中的无效区域使用不透明黑色填充。
- 重复应用相同角度不会重新生成图像，也不会清除当前状态。
- 加载新图片时自动恢复到 `0°`；切换到不同角度时清除旧 ROI、辅助图形和 Pick 状态。

### 中心翻转

- `Vertical Flip` 绕当前旋转画布的竖直中轴进行左右翻转。
- `Horizontal Flip` 绕当前旋转画布的水平中轴进行上下翻转。
- 两个按钮都是独立的切换状态，可以单独启用或组合启用。
- 翻转始终应用在绝对旋转结果之后；改变旋转角度时保留当前翻转状态。
- 加载新图片时取消两个翻转状态。
- 每次改变翻转状态都会重新设置主图，并清除旧 ROI、辅助图形、Pick 坐标和强度曲线。

## 像素 Pick 与行列强度剖面

选择 `Pick` 工具后，在图片有效内容上单击一个像素：

1. 主视图显示天蓝色像素标记，以及对应原图行、列的黄色参考线。
2. 工具栏显示该像素相对于未旋转原图的零基整数坐标 `X/Y`。
3. 窗口下方的两个 Qwt 图表分别显示该像素所在完整行和完整列的强度分布。

即使主图已经旋转或翻转，Pick 位置和剖面数据仍会通过组合坐标变换映射回未变换原图。因此旋转造成的黑色无效区域不能产生有效 Pick；在无效区域单击会清除已有 Pick 和曲线。

| 图表 | 固定坐标 | 采样方向 | 横轴范围 |
| --- | --- | --- | --- |
| `X Intensity Profile` | 所选像素的 Y，即所在行 | 沿 X 方向读取整行 | `0` 到 `width - 1` |
| `Y Intensity Profile` | 所选像素的 X，即所在列 | 沿 Y 方向读取整列 | `0` 到 `height - 1` |

曲线显示规则：

- 单通道灰度图显示一条 `Gray` 曲线。
- 彩色图显示 `R`、`G`、`B` 三条曲线。
- 8 位图像使用 `0–255` 强度范围。
- 16 位整数图像使用 `0–65535` 强度范围。
- 图表支持鼠标滚轮缩放和鼠标平移。
- 删除 Pick、加载新图或改变旋转角度时，坐标和两组曲线同步清空。

## 常用操作

| 操作 | 输入方式 |
| --- | --- |
| 加载图片 | 单击 `Load Image` |
| 缩放主图 | 在主视图中滚动鼠标滚轮 |
| 平移主图 | 按住鼠标右键拖动 |
| 选择 ROI | 选择 `ROI` 后按住左键拖动 |
| 绘制辅助图形 | 选择 `Line`、`Circle` 或 `Rect` 后按住左键拖动 |
| 取消正在绘制的图形 | 绘制过程中按鼠标右键 |
| 选择已有辅助图形 | 选择与图形相同的工具后单击其轮廓 |
| 删除辅助图形 | 选中图形后按 `Delete` |
| Pick 像素 | 选择 `Pick` 后单击图片有效内容 |
| 删除 Pick | 保持 `Pick` 模式并按 `Delete` |
| 旋转图片 | 选择目标角度后单击 `Rotate` |
| 左右翻转 | 单击 `Vertical Flip` 切换状态 |
| 上下翻转 | 单击 `Horizontal Flip` 切换状态 |

## 技术架构

### `image_viewer::ImgGraphicsView`

继承自 `QGraphicsView`，负责图片显示和主视图交互：

- 使用 `QGraphicsScene` 管理图片、ROI、辅助图形和 Pick 覆盖项。
- 处理滚轮缩放、右键平移、左键工具、图形选择和删除。
- 在视口覆盖层中绘制动态缩略导航，不让导航图随场景变换。
- 将当前旋转画布中的 Pick 坐标映射回原图坐标。
- 通过 `roiSelected`、`zoomChanged`、`pixelPicked` 和 `pixelPickCleared` 信号向窗口层报告状态。

### `image_viewer::ImageViewerWindow`

- 加载并保存原始 `QImage`。
- 从原图生成绝对旋转与双向翻转组合后的当前图像和坐标变换。
- 裁剪 ROI，并只在预览副本上绘制有效内容轮廓。
- 响应 Pick 坐标，生成灰度或 RGB 行列强度样本。
- 管理两个 `MultiCurvePlot` 控制器并同步界面状态。

### `MultiCurvePlot`

对 Qwt 多曲线图表进行封装：

- 使用稳定字符串 ID 管理 Gray、R、G、B 曲线。
- 支持整体替换、追加、读取和清空曲线数据。
- 管理坐标轴范围、曲线可见性、网格、图例、缩放和平移。

## 技术栈与环境要求

- CMake 3.16 或更高版本。
- C++20 编译器。
- Qt 6，使用 Core、Gui、Widgets、OpenGL、OpenGLWidgets 和 Svg 模块。
- Qwt 6.3.0。
- Windows MinGW64。

仓库已经包含 Windows MinGW64 使用的 Qwt 头文件、导入库和运行库：

```text
3rdparty/qwt/include
3rdparty/qwt/bin/mingw_win64/libqwt.a
3rdparty/qwt/bin/mingw_win64/qwt.dll
```

当前 CMake 配置会拒绝非 Windows 或非 MinGW 构建。使用的 MinGW ABI 需要与 Qt 和仓库内预编译 Qwt 库兼容。

## 构建与运行

推荐使用安装了 Qt 6 MinGW64 Kit 的 Qt Creator 打开项目根目录中的 `CMakeLists.txt`，选择匹配的 MinGW64 Kit 后配置并运行。

也可以在已配置 Qt/MinGW 环境的终端中构建。请将示例中的 Qt 路径替换为本机实际路径：

```powershell
cmake -S . -B build -G "MinGW Makefiles" `
    -DCMAKE_PREFIX_PATH="C:/Qt/6.x.x/mingw_64"
cmake --build build
```

构建完成后，CMake 会自动把 `qwt.dll` 复制到可执行文件目录。运行：

```powershell
.\build\QimageViewer.exe
```

## 图像格式与当前边界

- 文件选择器当前只开放 PNG、JPG/JPEG 和 BMP；实际解码能力还取决于 Qt 的图像格式插件。
- 当前数据层面向常见整数灰度、RGB 和 RGBA 图像，不支持 RAW、Bayer 或浮点图像数据。
- 非零角度旋转会将图像合成到黑色画布，因而不再保留透明背景的输出语义。
- 旋转图像和 ROI 保持为 `QImage` 数据；辅助标记只用于界面显示，不写入底层图像。
- 界面中的图片保存控件目前尚未连接业务逻辑，不属于已实现功能。
